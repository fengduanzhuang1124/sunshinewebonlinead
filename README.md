# Sunshine Health AD AI

This repository documents the iterative development of the Sunshine Health AI-assisted advertising workflow.

The project began as an internal rule-based advertising skill library and was progressively refined into production specifications, modular skills, validation rules, and AI video workflows.

Formal Git version control was introduced in September 2026.

Some historical source documents in this repository were developed before Git version control was introduced. These files are preserved in the `/historical` directory in their original version form.

Historical Git commit dates have not been backdated.

## Repository Structure

- `/historical` — archived pre-Git skill versions
- `/skills` — current active AI skills
- `/docs` — version history, architecture, development logs, and testing
- `/tests` — validation and regression test materials

## Current Development Direction

The system has evolved from a single broad AI advertising skill into a modular workflow consisting of:

- Retail Advertisement Skill
- Dynamic Video Advertisement Skill
- Product and information integrity rules
- Store and logo asset constraints
- Structured validation
- Quality assurance and testing

The repository is intended to preserve both historical development evidence and ongoing version-controlled system improvements.
